Deployment Guide

Software & Firmware Installation

Step-by-step instructions to compile firmware and host the Docker orchestration stack.

Flashing ESP32 Microcontroller via PlatformIO CLI

Ensure your ESP32 board is connected via Micro-USB or USB-C before initiating flashing procedures.

# 1. Clone repository
git clone https://github.com/hydropulse/hydropulse-core.git
cd hydropulse-core/firmware

# 2. Install PlatformIO Core CLI
pip install platformio

# 3. Build firmware project
pio run --environment esp32dev

# 4. Upload firmware to hardware and monitor serial output
pio run --target upload --target monitor --upload-port /dev/ttyUSB0

Backend Docker Compose Deployment

Launches MQTT broker (Mosquitto), Time-series database (InfluxDB), and Python API engine.

# Launch services in detached mode
docker-compose -f docker-compose.prod.yml up -d --build

# Verify operational container status
docker-compose ps

# View real-time MQTT telemetry log stream
docker-compose logs -f python-api-backend

Environment Variables (.env)

Create a .env file in the root directory prior to starting the containers.

# Network & Broker Setup
MQTT_BROKER_HOST=192.168.1.150
MQTT_BROKER_PORT=1883
MQTT_TOPIC_PREFIX=hydropulse/zone1

# Target Soil Moisture Thresholds (%)
MOISTURE_TARGET_MIN=35.0
MOISTURE_TARGET_MAX=65.0

# Fluid Dosing Tolerances
TARGET_PH_LEVEL=6.2
TARGET_EC_MILLISIMENS=1.8
PUMP_SAFETY_TIMEOUT_SECONDS=15
